Automated scripts for processes in Duolatera, by Tsingtao Zhang



Details of each tool can be found here: https://zhangtsingtao.github.io/portfolio-website/Duolatera.html

#### Custom Asset Pipeline Importer:

The importer automatically detects new assets from external directory, imports all associated files (mesh and textures), and creates a material instance inherited from our master material.

#### Albedo To RGB Channel Mask conversion tool:

​	Automatically clusters albedo texture, and reassign color values into RGB, therefore it works in our custom shader.

#### Renaming Tool

Validates all file names.

#### Quick Asset Check Blender Add-on

Automatically pieces assets (texture and mesh) for checking the asset before importing into Unreal.
